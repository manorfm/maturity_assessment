# Backlog de evolução

Este diretório guarda ideias, hipóteses e extensões para revisitar. Estar aqui não
significa compromisso de implementação, ordem de prioridade ou inclusão no modelo
vigente.

Antes de promover um item, registrar:

- problema e público afetado;
- evidência de que o problema existe;
- hipótese de resultado;
- riscos éticos, de privacidade e de interpretação;
- menor experimento capaz de validar a ideia;
- mudanças necessárias na base de conhecimento.

Os itens estão em `future-evolution.md`. Quando uma ideia for aceita, ela deve sair
do backlog e atualizar o modelo, a arquitetura ou um ADR correspondente.

Itens concluídos não permanecem marcados como `done` neste diretório. Eles são
removidos e recebem uma entrada resumida em `docs/history/completed.md`, enquanto a
especificação consolidada permanece na base de conhecimento.
